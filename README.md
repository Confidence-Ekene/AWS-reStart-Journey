# AWS-reStart-Journey


Welcome to my AWS reStart Journey repository. This repository captures my learning across cloud infrastructure, Linux administration, networking, cybersecurity, programming, databases, systems operations, automation, and artificial intelligence.
My goal is to build practical skills by completing labs, experimenting with AWS services, troubleshooting problems, and documenting what I learn.

* Cloud Computing: AWS fundamentals, EC2, S3, and cloud architecture
* Linux & Networking: Linux administration, Bash, IP addressing, VPCs, and subnetting
* Cloud Security: IAM, system hardening, CloudTrail, and security monitoring
* Programming: Python, SQL, debugging, and automation
* Databases: Amazon RDS, Aurora, and DynamoDB
* Cloud Operations: AWS CLI, CloudWatch, Systems Manager, and troubleshooting
* Automation & Scaling: CloudFormation, Lambda, load balancing, and Auto Scaling
* AI & Machine Learning: Amazon Bedrock, SageMaker, PartyRock, and prompt engineering
