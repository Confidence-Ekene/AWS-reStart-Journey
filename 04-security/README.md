# Cybersecurity & AWS Cloud Security

## Overview
This section documents my learning journey in cybersecurity and AWS cloud security as part of the AWS re/Start program. My focus is on understanding security fundamentals, protecting cloud resources, managing access, monitoring activity, and learning how to identify and respond to potential security issues.

## Topics Covered
- Security Fundamentals and Acceptable Use Policies
- Security Lifecycle: Prevention, Detection, Analysis, and Response
- Network Hardening
- System Hardening
- Data Protection and Data Security
- Public Key Infrastructure (PKI)
- AWS Certificate Manager (ACM)
- Identity and Access Management (IAM)
- Security Monitoring and Detection
- AWS CloudTrail
- AWS Config
- Amazon EC2 Monitoring
- AWS Trusted Advisor
- AWS Security Best Practices and Compliance

## Hands-on Labs
- Network Hardening
- Systems Hardening
- Data Protection
- Introduction to Identity and Access Management (IAM)
- Firewall and Malware
- Monitoring an EC2 Instance

## Skills Developing
- Understanding the principles of confidentiality, integrity, and availability
- Applying foundational network and system hardening concepts
- Understanding identity, authentication, authorization, and access control
- Exploring IAM users, groups, roles, and policies
- Understanding encryption, certificates, and secure communications
- Learning how CloudTrail records account activity
- Exploring AWS Config for resource configuration tracking
- Understanding monitoring, threat detection, incident analysis, and response
- Developing awareness of AWS compliance requirements and security best practices

## Practical Applications
These concepts support the secure configuration of AWS environments, protection of sensitive information, monitoring of cloud resources, investigation of suspicious activity, and reduction of unnecessary access.

## Learning Goals
Continue building practical cloud security skills and develop a security-first approach to infrastructure management, troubleshooting, and cloud operations.
