# Computer Networking & AWS Networking

## Overview
This section documents my learning journey in computer networking and AWS networking through the AWS re/Start program. I am building an understanding of how devices communicate, how IP addressing works, and how cloud network resources are configured and connected.

- Subnetting and Network Segmentation
- Amazon Virtual Private Cloud (Amazon VPC)
- VPC Subnets and Networking Resources
- Additional Networking Protocols and Technologies
- Network Troubleshooting Commands
